# HALVETH SCARLET

Eine leuchtende Erdansicht, eine schwebende Frage und ein Tagesring, der jeden Berliner Kalendertag neu beginnt.

**Website:** https://juri-halveth.github.io/halveth-scarlet/

Die Seite besteht aus statischem HTML, CSS und JavaScript. Sie benötigt keine zusätzliche Domainregistrierung. Die Oberfläche enthält einen Regler, eine Pausefunktion und eine kurze Nachricht von HALVETH. Unter „Forschungsnotiz“ steht ein Quellenvergleich zu biologischen Formen und Kalenderbezeichnungen.

## Quellen

- Erdtextur: [NASA Blue Marble](https://science.nasa.gov/earth/earth-observatory/the-blue-marble-true-color-global-imagery-at-1km-resolution/) — NASA GSFC, Reto Stöckli / Robert Simmon. Die Darstellung ist eine Textur, kein Live-Satellitenbild.
- Die astronomische Anzeige nutzt die Gerätezeit als Näherung. Die Tagesanzeige folgt Europe/Berlin.
- Die Forschungsnotiz verlinkt ihre wissenschaftlichen und historischen Quellen unmittelbar im Text. Sie berichtet keine eigene experimentelle Entdeckung.

## English

HALVETH SCARLET is a static, interactive Earth visualization with a daily ring and a floating Scarlet Witch question. The daily ring follows the Europe/Berlin civil clock. Source references and the research note are available within the site. The visualization is a creative web project, not a measurement instrument.

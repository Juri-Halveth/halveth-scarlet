# SCARLET · Автономное рабочее пространство

[Технические демонстрации](https://juri-halveth.github.io/halveth-scarlet/forschung/wegweiser/ru.html)
· [Рабочее пространство](https://juri-halveth.github.io/halveth-scarlet/)

Локальное пространство для текстовых состояний, вариантов и наблюдения. На входе работает существующий журнал GStar и отдельная конечная клеточная симуляция GStar Living. Сохраняйте вход, создавайте варианты, наблюдения и снимки, проверяйте повтор и экспортируйте реальные записи. Нативный код в `native/`
имеет отдельный охват сборки и измерений.

Сборка: `node tools/build_site.mjs`. Проверка: `node --test tests/*.test.cjs tests/*.test.mjs`.
Прежние личные и политические страницы сохранены приватно.
[Общественный проект JURI-THESIS](forschung/juri-thesis/) вновь открыт как
отдельное исключение. Этот коммит не переписывает историю Git.

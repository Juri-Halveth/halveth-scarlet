# SCARLET · Игры, графика и технические модели

[Технические демонстрации](https://juri-halveth.github.io/halveth-scarlet/forschung/wegweiser/)
· [Сцена Земли](https://juri-halveth.github.io/halveth-scarlet/)

Браузерные игровые прототипы, интерактивная графика и синтетические учебные модели.
У каждого проекта свой вход и состояние разработки. Нативный код в `native/`
имеет отдельный охват сборки и измерений.

Сборка: `node tools/build_site.mjs`. Проверка: `node --test tests/*.test.cjs tests/*.test.mjs`.
Прежние личные и политические контекстные страницы сохранены приватно и удалены
из текущего публичного дерева. Этот коммит не переписывает историю Git.

# HALVETH Scarlet

**Краткий путеводитель по проекту · EN / RU**

Визуальный портал Земли, соединяющий исследовательские страницы, профили персонажей и ссылки на источники. Сайт сочетает анимированную сцену, события по времени, включаемый пользователем синтезированный звук и опубликованный снимок новостей с видимыми датами источников.

Персонажи и их роли — авторские перспективы проекта и фанатские интерпретации. Они не устанавливают наличие независимо работающих агентов или контроль над внешними организациями. Этот веб-проект имеет собственные результаты и историю публикаций, отдельно от нативного Morrowind.

Этот путеводитель составлен и отредактирован вручную по проверенному источнику. Исходная техническая документация остаётся справочным материалом для команд, требований сборки, точных версий и подробных проверок.

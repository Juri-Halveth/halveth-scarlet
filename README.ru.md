# SCARLET · Интерактивное пространство состояний и вариантов

Локальный прототип в браузере для текстовых состояний, вариантов и наблюдения. На входе работает журнал GStar и отдельная конечная клеточная симуляция GStar Living. Можно сохранить ввод, создать вариант, снимок, повторное воспроизведение и экспорт записей. Нативный код в `native/` имеет отдельный охват сборки и измерений.

[**Открыть рабочее пространство напрямую**](https://juri-halveth.github.io/halveth-scarlet/) · [Технические демонстрации](https://juri-halveth.github.io/halveth-scarlet/forschung/wegweiser/ru.html) · [Исходный код](https://github.com/Juri-Halveth/halveth-scarlet/tree/main)

Сборка: `node tools/build_site.mjs`. Проверка: `node --test tests/*.test.cjs tests/*.test.mjs`.

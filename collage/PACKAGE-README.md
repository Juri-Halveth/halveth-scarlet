# HALVETH Choice Atelier 1.0.0

This release contains the original Choice Atelier artwork, its delivery
derivatives, the recorded generation brief, the artwork integrity record and
the finite Pinterest source review used by the public portal.

## Package boundary

Included:

- two unmodified PNG source artifacts created for this project;
- two optimized WebP delivery derivatives;
- the recorded generation brief and visual inspection;
- the machine-readable artwork record;
- the bilingual Pinterest source review and source register;
- the repository license map and assigned public-interest license.

Excluded:

- Pinterest pins or other third-party imagery;
- private screenshots, account data or browser state;
- unrelated downloads, games or torrent payloads;
- any claim about a named person's welfare, consent or account control.

`SHA256SUMS.txt` binds every payload file in this ZIP. The adjacent release
receipt binds the ZIP, BitTorrent v1 descriptor and magnet URI. Hashes identify
bytes; they do not establish authorship, creation time, legal ownership or live
peer availability.
